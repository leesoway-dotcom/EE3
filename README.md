## 🛠️ 主要功能說明

1. **多模態情緒感知**：結合視覺 (鏡頭) 與觸覺 (IMU/IR)，即時分析使用者心情。
2. **零螢幕沉浸式對話**：使用者可直接與絨毛玩具說話，玩具會以符合情境的音調與動作回應。
3. **雙模互動機制**：支援直接語音對話與手機 Edge AI App 管理介面。
4. **離線安全陪伴**：斷網時仍能透過 AMB82-mini 本地端 SD 卡播放內建撫慰音樂與語音。

* **組員 B**：Edge AI Gemma4-E2B 模型串接與語音/影像處理流程開發
